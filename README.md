# 拼多多订单导出工具

在[拼多多移动网页版订单页](https://mobile.pinduoduo.com/orders.html)收集当前账号订单，在本机导出 CSV 账单或 JSON 数据。

## 安装

支持 Edge、Chrome 136+。安装 Tampermonkey 后，点击[安装固定版脚本](https://github.com/PG2047/pdd-order-export/releases/download/v2026-10-25.4/pdd-order-export.user.js)，在脚本管理器中确认安装。也可从[发布页](https://github.com/PG2047/pdd-order-export/releases/tag/v2026-10-25.4)下载后导入。固定版为 `2026-10-25.4`，四个依赖均固定 SHA-256，并关闭脚本自动更新。已安装上一版固定版时，用此文件更新；只启用一个版本。刷新页面前，先导出页面中已有的结果。面板显示当前固定版版本号。

上游项目为 [aqni/pdd-order-export](https://github.com/aqni/pdd-order-export)，此 fork 保留上游 MIT 许可，固定版不会自动同步上游发布。

登录订单页，点击右下角「导出账单」。范围设置、收集进度与导出选项均在面板内。

点击「收起」或按 Esc 只收起面板，收集会继续运行；再次打开可查看进度和结果。需要中止时，点击「停止并保留结果」。

设置日期范围后，无法从编号判断日期的订单仍会保留，面板会提示数量。CSV 的「日期核对」列标记这些订单；JSON 用 `dateUncertain: true` 标记。它们可能超出所选日期范围，请按下单时间核对。

网络或详情读取中断时，可以导出已经完成的订单，文件名和按钮会标明结果不完整。未知异常只显示失败步骤和错误类别，不显示订单内容或凭据。

单笔详情页没有可解析数据时，保留该笔订单的列表信息，继续收集其他订单。不再按连续解析失败次数暂停详情。登录失效、访问被拒绝、请求失败或详情订单号不匹配时仍停止收集。

缺少详情时，面板会显示数量；CSV 增加「详情状态」列，JSON 用 `detailFailure` 标记。订单列表收集完成但详情有缺失的文件名含「详情不完整」；收集中途停止的文件名含「不完整」。未勾选「收集详情」属于主动选择，不标记为失败。列表中的金额、商品等字段照常保留；缺少的详情字段不会补造。

## 补齐已有订单的详情

在「补齐已有订单详情」中选择「导入已有 JSON」，导入此前导出的 JSON 文件。导入只在本机读取，不发送文件内容。确认面板中的订单数、已有详情数和待补数量，再点击「仅补齐缺失的 N 笔详情」。不要点击「重新收集」。

补齐仅请求 `detail: null` 的订单，保留所有原订单及顺序，已有详情不重复请求、不覆盖。不读取订单列表，不自动重新分页。每笔仍无法解析时保留失败标记并继续后面的缺失订单；补齐模式不按连续失败次数暂停。登录失效、访问被拒绝、限流、其他请求错误、订单号不匹配和主动停止仍会中断补齐，保留已取得的更新。

结束或中断后导出新的 JSON 和 CSV。文件名含「导入订单_补齐详情」，不会写入原文件。再次导入新 JSON，可继续处理仍缺少的详情。导入数组不含原收集日期范围及列表完整性，面板会说明范围沿用导入文件，不声称重新确认了全部历史订单。

## 数据与隐私

订单 JSON、CSV 及导入文件在本机处理。详情请求发送到拼多多官网，使用浏览器当前登录状态。脚本不向此 GitHub 仓库上传订单数据。安装时，脚本管理器从 jsDelivr 加载四个固定版本的依赖，并校验 SHA-256；脚本图标来自 Google favicon 服务。

不要在 issue、提交或附件中放入真实订单、Cookie、UID、收件信息、手机号、地址或账号截图。仓库测试使用合成数据，不能代替当前账号及官网的兼容性验证。
